# TSSL HR Training

## Project Overview

This project is an HR application designed to make it easier to manage employee information and organise human resource activities. It aims to reduce manual record-keeping and make HR information easier to access and manage.

## Planned Features

* **Employee Records:** Store and manage employee information.
* **Attendance Tracking:** Record and monitor employee attendance.
* **Leave Management:** Allow leave requests to be recorded and tracked.

### How to Open the Project

1. Open the project folder.
2. Navigate to the `week02` folder.
3. Open `index.html` in a web browser.
4. Use the navigation link to access the Employee Profile Form.

### Employee Profile Form

The form collects basic employee information, including Employee ID, full name, email address, department, start date and employment type. It also includes optional telephone, notes and emergency contact fields.

**Note:** This form is for demonstration purposes only. It does not save employee records or store submitted information.

## Week 3: Responsive Employee Directory

The Week 3 project improves the employee directory using CSS Flexbox, CSS Grid and responsive media queries.

### Features
- Responsive navigation using Flexbox.
- Employee cards arranged using CSS Grid.
- Six fictional employee records.
- Responsive layouts for mobile, tablet and desktop screens.
- Employee work locations and status labels.
- Visible keyboard focus indicators.
- Long text wrapping to prevent horizontal overflow.

### How to Open the Directory

1. Open the `week03` folder.
2. Locate `index.html`.
3. Open it in a web browser.

The main employee directory uses local HTML and CSS files and works without an internet connection.

### Tailwind CSS Comparison

A separate `tailwind-demo.html` file was created to demonstrate Tailwind CSS utility classes. It is not part of the main employee directory.

### Project Limitations

This is a static demonstration project. It does not search employee records, save employee data or provide user account access.
