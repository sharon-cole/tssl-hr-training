# HR Application — Project Brief

## Intended Users

1. **HR Managers:** Manage employee records, review leave requests, and oversee HR activities.
2. **Employees:** View their personal information and submit leave requests.
3. **Administrators:** Manage user accounts and control access to the application.

## Planned Features

1. **Employee Management:** Add, view, update, and manage employee information.
2. **Leave Request Management:** Allow employees to submit leave requests and enable HR managers to approve or reject them.
3. **User Authentication:** Allow users to log in securely according to their roles and permissions.

## Benefit of the Application

The HR application will make human resource management easier by reducing paperwork, organizing employee records, and improving the processing of leave requests.
