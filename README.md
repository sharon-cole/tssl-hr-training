# TSSL HR Training

## Project Overview

This project is an HR application designed to make it easier to manage employee information and organise human resource activities. It aims to reduce manual record-keeping and make HR information easier to access and manage.

## Planned Features

* **Employee Records:** Store and manage employee information.
* **Attendance Tracking:** Record and monitor employee attendance.
* **Leave Management:** Allow leave requests to be recorded and tracked.
